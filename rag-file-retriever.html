RAG File Retriever

A local file retrieval prototype that uses embeddings to find files by meaning rather than exact filename or keyword matches.

Built with Python, FAISS, and Sentence Transformers, with a CLI for local retrieval.

Python FAISS Sentence Transformers CLI

01 / The problem

The problem this project addresses.

Traditional filename or exact-term searches miss documents that express a relevant idea using different wording.

02 / What I built

Capabilities and technical approach.

Start with a local embedding-based prototype, then improve retrieval quality, maintainability, and evaluation in phases rather than treating a prototype as a finished RAG system.
